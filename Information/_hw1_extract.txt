5. Perceptron(10 points)
Background.The perceptron is a linear classifier that predicts a class using a weighted sum of the input features
and a bias term. During training, it updates its weights when an example is misclassified, moving the decision
boundary toward correctly classifying that example. In this assignment, the input features are TF-IDF vectors.
We use the classic perceptron, which has no hidden layers and is different from a multilayer perceptron (MLP).
For an introduction, see Eisenstein, Section 2.3.1. For implementation details, see the scikit-learn Perceptron
documentation.

random_state=42, max_iter=1000, and tol=1e-3. Return the fitted model; have the script print its eight

7. Multinomial Naive Bayes(10 points)
Background.Naive Bayes classifies documents using Bayes’ theorem and the assumption that features are
conditionally independent given the class. Multinomial Naive Bayes estimates class-specific word probabilities
from feature counts and combines them with class prior probabilities to make predictions. Although originally
formulated for word counts, it is also commonly applied to nonnegative TF-IDF features, as in this assignment.
The parameteralpha=1.0 applies Laplace smoothing to avoid zero probabilities for features absent from a class’s
training examples. “Multinomial” describes the feature model; it does not require more than two output classes.
See Eisenstein, Section 2.2 and the scikit-learn Multinomial Naive Bayes documentation.
For model name"Naive Bayes", trainsklearn.naive_bayes.MultinomialNB with alpha=1.0 and other default
settings on the same nonnegative TF-IDF features. Return the fitted model; have the script print its eight
training/test metrics.
